# Web Development - I (JavaScript) Practical Assignment 1

## **Instructions:**
- Take input using a form and suitable input field(s).

## **Programs List**

### **Numbers**
1. **Reverse a number.**  
2. **Convert temperatures between Celsius and Fahrenheit.**  
3. **Check if an input number is prime or not.**  
4. **Calculate the factorial of a number using recursion.**  

### **Strings**
5. **Check if a string is a palindrome.**  
6. **Convert the first letter of each word in a string to uppercase.**  
7. **Get the extension of a filename.**  
8. **Find the longest word within a string.**  

### **Date Operations**
9. **Add specified minutes to a Date object.**  
10. **Determine whether the current year is a leap year or not.**  
11. **Get the difference between two dates in days.**  
12. **Calculate age from birth date.**  

### **Arrays**
13. **Find the largest of five numbers and display an alert box with the result.**  
14. **Compute the sum of an array of integers.**  
15. **Implement a binary search algorithm.**  
16. **Implement a merge sort algorithm.**  
17. **Join all elements of an array into a string using a given delimiter.**  
   - **Input Array:** `myArr = ["str1", "str2", "str3"]`
   - **Output:** `"str1, str2, str3"` OR `"str1+str2+str3"`
18. **Convert a string to an array (Reverse of the previous program).**  
19. **Decompose parts of an input URL.**  
   - **Example:**
     - **Input:** `http://www.google.com/page1.html`
     - **Output:**
       - **Protocol:** `http`
       - **Domain:** `www.google.com`
       - **Page:** `page1`
       - **Extension:** `html`

### **DOM Manipulation**
20. **Get the values of all attributes (`href`, `hreflang`, `rel`, `target`, and `type`) of a specified hyperlink and image.**  
21. **Add rows to a table dynamically.**  
22. **Count and display all `<h1>` elements on the document.**  
23. **Change the color of all paragraphs based on input from a text box.**  
24. **Change the dimensions (height and width) of an image based on input values.**  
25. **Display all elements (textbox, radio, etc.) of a form along with their values.**  
26. **Count and display the items of a dropdown list in an alert window.**  
27. **Populate a combo box using given array elements.**  
28. **Get the width and height of the window (any time the window is resized).**  
29. **Validate a form using JavaScript and display error messages in red.**  
   - If no errors, show a success message in green.
   - Form fields to validate:
     - **Name:** Should not be blank.
     - **Age:** Should be between **15 to 20**.
     - **Gender:** Required field.

---
### **How to Run the Programs**
Each program should be implemented in a separate JavaScript file and included in an HTML page. Run the HTML page in a web browser to test the functionality.
